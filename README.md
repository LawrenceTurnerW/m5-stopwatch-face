# M5 StopWatch 着せ替え時計

M5Stack StopWatch を、ブラウザから着せ替えられる時計にするプロジェクトです。Web Bluetooth でつなぎ、テーマ(色・文字盤画像・効果音)とミニアプリ(JavaScript)を送り込みます。サーバーは使いません。

- **サイト**: https://m5-stopwatch-face.lawrenceturnerw.workers.dev
- **本体の準備(ファームウェアの書き込み手順)**: https://m5-stopwatch-face.lawrenceturnerw.workers.dev/install

M5Stack 公式のものではない、個人のプロジェクトです。無保証です。

## 注意

- 専用のファームウェアを書き込むので、本体に入っているファームウェアは上書きされます。元に戻せるよう、書き込む前にバックアップを取ってください(手順は上の「本体の準備」にあります)。
- 本体との Bluetooth 通信には認証も暗号化もありません。電波の届く範囲にいる人なら誰でも、テーマやアプリを本体に送れます。
- 実機での確認はまだ一部だけです。何を確かめたかは末尾の「実機で確かめたこと」を見てください。

## 全体構成

```
┌─ ブラウザ (web/index.html) ───────────────┐          ┌─ StopWatch (src/) ─────────────────────┐
│ テーマ編集   色 / 文字盤の切り抜き / 効果音 │          │ 時計 (テーマカラーで描画)               │
│ アプリ編集   エディタ + 隔離プレビュー      │ ── BLE ─▶│ ファイル受信 → LittleFS に保存          │
│ 共有         文字列 / リンク / ファイル     │ ◀─ ログ ─│ ミニアプリ実行環境 (QuickJS + API)      │
└───────────────────────────────────────────┘          └────────────────────────────────────────┘
```

| 部分 | 場所 | 役割 |
|---|---|---|
| ファームウェア本体 | `src/main.cpp` | 時計の表示、BLE の受信、画面の切り替え、アプリから見える本体機能の実装 |
| ミニアプリ実行環境 | `src/app_runtime.cpp` `src/app_host.h` | QuickJS の上にアプリ用 API を載せ、メモリ・時間・スタックを制限する。本体には `AppHost` 経由でしか触れない |
| JS エンジン | `lib/quickjs/` | QuickJS-ng v0.18.0 を無改変で同梱(ESP32 用の補助は `esp32_port.c` のみ) |
| サイト | `web/index.html` | テーマとアプリの作成・プレビュー・転送・共有。1 ファイルで完結 |
| サンプルアプリ(ギャラリー) | `web/apps/` | `index.json` に並べたアプリがサイトに出る |
| PC 上のテスト | `tools/host-test/` | 実行環境を PC でビルドして動かす(メモリ破壊の検出つき) |
| サイトの通しテスト | `tools/browser-test/` | 疑似 BLE デバイスを相手にサイトを動かし、プレビューと実行環境の結果が一致することを確かめる |

## 使い方

1. [本体の準備](https://m5-stopwatch-face.lawrenceturnerw.workers.dev/install)の手順でファームウェアを書き込みます。自分でビルドする場合は下の「ビルド」を見てください。
2. PC か Android の Chrome / Edge で[サイト](https://m5-stopwatch-face.lawrenceturnerw.workers.dev)を開きます。
3. 「接続」を押して `M5StopWatch` を選びます。時刻は接続時に自動で合います。

本体の操作は次のとおりです。

| 画面 | 操作 |
|---|---|
| 時計 | A・タップ = 効果音、B = アプリ一覧。時刻の上に電池残量と充電の状態が出る |
| アプリ一覧 | A = 次へ、B・タップ = 決定。先頭の「設定」で、明るさ・音量・振動を変えられる |
| 設定 | タッチで変更(左半分で下げる、右半分で上げる)、B = 戻る |
| アプリ中 | A・B・タップはアプリに渡る |
| どこでも | A と B を同時に長押し = 時計に戻る |

## テーマ

テーマは 6 色と文字盤画像と効果音のまとまりです。時計もミニアプリもこの色で描きます。

| 役割 | アプリでの名前 | 使いどころ |
|---|---|---|
| 背景 | `theme.bg` | 画面の地 |
| 面 | `theme.surface` | ボタンやリングの下地 |
| 文字 | `theme.fg` | 主な文字 |
| 控えめ | `theme.muted` | 補助の文字、目盛り |
| 強調 | `theme.accent` | 進み具合、選択中 |
| 強調 2 | `theme.accent2` | 秒針、警告 |

共有のしかたは 3 つあります。

- **文字列**: `#101216,#1A1D24,#E8EAF0,#9AA1B0,#5CC8FF,#FFA500` を貼り付けると色が切り替わります。
- **リンク**: `…/index.html#theme=101216,1A1D24,…` を開くと色が切り替わります。
- **みんなの配色**: 配色に名前を付けて投稿すると、サイトの一覧に載り、誰でも選べます(色だけ。文字盤の画像と効果音は含みません)。

「本体に転送」を押すと、いま見えている色・文字盤・効果音をまとめて送ります。本体はサイトで見えているとおりになるので、文字盤の画像を選んでいなければ、本体の文字盤は目盛りだけに戻ります。

- **文字盤**: 画像は画面と同じ 466 ピクセルの JPEG にして送ります。透過のある画像は、透けた部分がテーマの背景色になります。
- **効果音**: 用意した 9 種類から選びます。音はサイト側で計算して作り、16 kHz・モノラルの波形として本体に送ります。
- **AI で色を作る**: 雰囲気を文章で頼むと、6 色を作ります。

## ミニアプリ

`draw()` を持つ JavaScript ファイル 1 つがアプリです。API の一覧はサイトの「アプリ」タブにあります。

```js
// @name はじめてのアプリ
let on = false;

function onButton(b) {
  on = !on;
  watch.vibrate(40);
}

function draw() {
  g.clear();
  g.fillCircle(233, 233, 120, on ? theme.accent : theme.surface);
  g.text(on ? "ON" : "OFF", 233, 233, { size: 64, color: on ? theme.bg : theme.fg });
}
```

### 制限

アプリが使えるのは JavaScript の標準機能と、`g` `theme` `watch` `store` `print` だけです。通信・ファイル・GPIO・タイマー(`setTimeout`)はありません。

| 項目 | 上限 | 超えたとき |
|---|---|---|
| スクリプトの大きさ | 64kB | 受け取らない |
| メモリ | 1MB | アプリを止める |
| 読み込みと `setup()` | 1 秒 | アプリを止める |
| `draw()` とイベント 1 回 | 0.25 秒 | アプリを止める |
| 保存領域(`store`) | JSON で 4096 バイト | 例外になる |
| `print()` | 1 回の呼び出しにつき 8 行 | 超えたぶんは捨てる |
| 振動 / ビープ音 | 1 秒 / 2 秒 | 短く切り詰める |
| アプリの数 | 8 個 | - |

止めたときは理由を画面とサイトのコンソールに出します。A と B の同時長押しは実行環境の外で処理するので、アプリからは止められません。

### 公開のしかた

- **リンク共有**: サイトの「共有リンクをコピー」で、スクリプトを圧縮して URL の `#` 以降に入れたリンクができます。サーバーには何も送られません。開いた人はコードとプレビューを見てから本体に送ります。
- **ギャラリー**: `web/apps/` に `.js` を置き、`web/apps/index.json` に 1 行足すプルリクエストを出します。レビューが審査を兼ねます。

### プレビューと本体を同じに保つ

プレビューは、隔離した iframe の中の Worker でアプリを動かします(ページ本体・Bluetooth・通信には触れません)。API の実装は 2 か所にあります。

- 本体: `src/app_runtime.cpp`(引数の変換) + `src/main.cpp` の `DeviceHost`(描画)
- プレビュー: `web/index.html` の `previewShim`

引数の丸め・既定値・色の解釈・フォントサイズの丸めは両方で同じ規則にしてあり、`tools/browser-test/test.js` が API 呼び出しの記録を突き合わせて確かめます。API を変えるときは両方を直してテストを通してください。

## BLE プロトコル

`src/main.cpp` の冒頭にコマンドの一覧があります。ファイル転送は、CTRL に BEGIN(種類・サイズ・CRC32)を書き、DATA に本体を流し、STATUS の通知で受信済みバイト数を確かめながら進めます。最後に本体が CRC32 を照合して保存します。

## 投稿と AI 生成(サイトの裏側)

`worker/` が Cloudflare Workers で動く小さな API です。それ以外の URL は `web/` をそのまま返します。

| 機能 | 場所 | 内容 |
|---|---|---|
| みんなの投稿・みんなの配色 | `worker/index.js` | ミニアプリと配色を誰でも投稿でき、すぐ公開される。D1 に保存。削除は投稿したブラウザ(削除キー)か管理者トークン。別々の 3 人から通報されると一覧から外れる |
| AI に作ってもらう | `worker/generate.js` `worker/prompt.js` | 頼んだ内容のミニアプリや配色を、OpenRouter 経由の AI(既定は DeepSeek V4.1 Flash)に作らせる。API キーは Worker の秘密情報 |

荒らしと費用の歯止めは次のとおりです。

- 投稿・削除・通報・生成は、同じ IP から 1 分に 5 回まで。ほかのサイトからの呼び出しは断る
- 投稿は 64 kB まで、サイト全体で 1 日 300 件まで
- 生成は同じ IP から 1 日 50 回、サイト全体で 1 日 300 回まで。入力 400 文字、出力 12000 トークンまで
- OpenRouter のキー自体にも上限額を付けてある。入力を学習に使う提供元には流さない設定

IP アドレスそのものは保存しません(秘密の値を混ぜたハッシュだけ)。AI に送った文章も保存しません。

手元で動かすには、`.dev.vars` に `ADMIN_TOKEN=local-admin-token` と `TEST_MODE=1`(AI も試すなら `OPENROUTER_API_KEY`)を書いて次を実行します。

```sh
npx wrangler@4 d1 migrations apply m5-stopwatch-face --local
npx wrangler@4 dev --port 8787        # http://127.0.0.1:8787
node tools/api-test/test.js           # API のテスト(37 項目。AI は実際には呼ばない)
```

API のない場所(`python3 -m http.server` など)では、投稿と AI の欄は出ません。

## ビルド

[PlatformIO](https://platformio.org/) を使います。ライブラリの版は `platformio.ini` で固定してあります。

```sh
pio run                 # ビルド
pio run -t upload       # 書き込み(本体をダウンロードモードにしてから)
cd web && python3 -m http.server 8000   # サイトを手元で動かす(http://localhost:8000)
```

`pio` を入れていない場合は、[uv](https://docs.astral.sh/uv/) 経由でも動きます。

```sh
uv tool run --from platformio==6.1.19 --with pip pio run
```

ダウンロードモードにするには、電源ボタンを約 2 秒長押しして、内部の緑の LED が点いたら離します。

## 配布と公開

```sh
sh tools/make-firmware.sh     # 配布用の書き込みファイルを作る → web/firmware/m5-stopwatch-face.bin
npx wrangler@4 d1 migrations apply m5-stopwatch-face --remote   # データベースの更新(変更があるとき)
npx wrangler@4 deploy         # web/ と worker/ を Cloudflare Workers に載せる(設定は wrangler.jsonc)
```

書き込み用ファイルは git には入れていません。サイトと GitHub の Releases から取れます。ブートローダー・パーティション表・アプリを 1 つにまとめたもので、`0x0` から書き込みます。

## 実機で確かめたこと

実機で確かめたのは次の点です(2026-11-27 時点)。

- `pio run -t upload` と、配布用のまとめたファイル(`uvx esptool … write-flash 0x0`)のどちらでも書き込めること。書き込み後は電源ボタンを 1 回押すと起動する
- BLE でデバイス一覧に出て接続でき、接続時の時刻合わせが通ること(MTU 517)
- 時計画面に電池残量と「充電中」が出て、USB を抜くと数秒で残量だけの表示に変わること
- テーマカラーとミニアプリの転送が成功すること(ストップウォッチ 1.4kB で 0.14 秒)
- 加速度の向き。センサーが画面に対して 90 度回って付いていたので本体側で直し、水平器で向きが合うことを確認した

次の点は、実機ではまだ確かめていません。

- 設定画面(明るさ・音量・振動)の動作と、値が再起動後も残ること
- タッチを「触れた瞬間」に渡す変更で、けんばんの取りこぼしが直ったか
- 「消す」の依頼を続けて受けても取りこぼさないようにした変更(v0.3.0 の最後に入れたもの。この版は実機に書き込んでいない)
- 文字盤画像の転送と、大きなファイルでの転送速度
- サンプルアプリの大半と、AI が作ったアプリの動作
- `draw()` 1 回に何ミリ秒かかるか、画面全体の書き換えで何 fps まで出るか
- 数字フォントの大きさなど、プレビューとの見た目の差

それ以外で確認済みなのは、実行環境が PC 上で動くこと、サイトが疑似デバイス相手に動くこと、投稿と AI 生成の API が手元の Worker で動くことまでです。
