アプリの書き方

      
画面は直径 466px の円です。draw() が 1 秒に何回か呼ばれるので、その中で毎回全体を描きます。色は theme から取ると、どのテーマにも馴染みます。プレビューと本体は同じ API で動きますが、本体はずっと遅いので、重い計算は避けてください。

      

      

        
書くもの内容

        
// @name 名前先頭のコメント。本体のアプリ一覧に出る名前

        
function setup()起動時に 1 回(省略可)

        
function draw()画面を描く(必須)。既定は 1 秒に 10 回

        
function onButton(b)ボタンが押された。b は "A" か "B"

        
function onTouch(x, y)画面に触れた(触れた瞬間に 1 回)

        
使えるもの

        
theme.bg / surface / fg / muted / accent / accent2テーマカラー(背景 / 面 / 文字 / 控えめ / 強調 / 強調 2)

        
g.clear(色) g.face()塗りつぶす(省略時は背景色) / テーマの文字盤画像を描く

        
g.fillRect(x, y, w, h, 色) g.rect(…) g.fillRoundRect(x, y, w, h, r, 色)四角形。色を省くと文字色

        
g.fillCircle(x, y, r, 色) g.circle(…) g.fillTriangle(x0, y0, x1, y1, x2, y2, 色)円と三角形

        
g.line(x0, y0, x1, y1, 色, 太さ)線

        
g.arc(x, y, 外半径, 内半径, 開始, 終了, 色)輪の一部。角度は 12 時が 0 度で時計回り

        
g.text(文字, x, y, { size, color, align, font, outline })文字。align は "left" / "center" / "right"、font: "digit" は数字用の大きな書体(高さ 75px)、outline は縁取りの色

        
g.textWidth(文字, { size, font })文字の幅(px)

        
watch.vibrate(ミリ秒) watch.tone(周波数, ミリ秒) watch.sound()振動 / ビープ音 / テーマの効果音

        
watch.accel() watch.battery()加速度 { x, y, z }(G)。x は右(3 時側)を下げると正、y は上(12 時側)を下げると正 / 電池残量(%)

        
watch.power()電源の状態。"battery"(電池で動作) / "charging"(充電中) / "usb"(USB につながっているが充電していない) / "unknown"

        
watch.frameRate(回数) watch.exit()draw() の頻度(1〜30) / 時計に戻る

        
store.load() store.save(値)アプリごとの保存領域(JSON で 4096 バイトまで)

        
print(…)下のコンソールに出す。console.log でも同じ

        
Date Math JSON などJavaScript の標準機能。setTimeout や通信はありません

        
制限

        
大きさ・メモリスクリプト 64kB まで、メモリ 1MB まで

        
時間draw() やイベント 1 回が 0.25 秒、読み込みと setup() が 1 秒を超えると止められる

        
戻り方本体では A と B の同時長押しで、いつでも時計に戻る
