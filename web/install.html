本体の準備

着せ替えサイトへ GitHub

M5Stack StopWatch を着せ替え時計にするには、専用のファームウェアを本体に書き込みます。このページの手順を上から進めると、10 分ほどで終わります。

必要なもの: M5Stack StopWatch、データ通信のできる USB-C ケーブル、PC(macOS / Windows / Linux)。

先に知っておくこと

  • M5Stack 公式のものではない、個人が作ったファームウェアです。無保証です。
  • いま本体に入っているファームウェアは上書きされます。元に戻したいときのために、手順 2 のバックアップを取っておくことをおすすめします。
  • 本体との Bluetooth 通信には認証がありません。電波の届く範囲にいる人なら誰でも、このサイトからテーマやアプリを送れます。

1書き込みツールを用意する

Espressif 公式の esptool を使います。どちらか片方で構いません。

uv が入っていれば、インストールは要りません。uvx esptool がその場で取ってきて実行します。

uvx esptool version

Python 3.10 以降が必要です。

pip install esptool

2ダウンロードモードにして、いまの中身をバックアップする

本体を USB でつなぎ、電源ボタンを約 2 秒長押しします。内部の緑の LED が点いたら離してください。これで書き込みを受け付ける状態になります。

続けて、いまのフラッシュ全体(16 MB)をファイルに保存します。数分かかります。

ポートは自動で探します。見つからないときは --port /dev/cu.usbmodem101(Windows なら --port COM5 など)を --chip の前に足してください。別のアプリがシリアルポートを開いていると失敗します。

3ファームウェアをダウンロードする

m5-stopwatch-face.bin をダウンロード

約 3.9 MB。SHA-256: (読み込み中)

ブートローダー・パーティション表・アプリを 1 つにまとめたファイルです。ソースコードは GitHub にあり、自分でビルドすることもできます。

4書き込む

ダウンロードしたファイルのあるフォルダで実行します。本体がダウンロードモードから抜けていたら、もう一度電源ボタンを長押ししてください。

Hash of data verified. と出れば成功です。30 秒ほどで終わります。途中で止まっても、ダウンロードモードは本体の ROM の機能なので、やり直せます。

5起動して、サイトからつなぐ

書き込みが終わると本体が再起動して、時計が表示されます。画面が暗いままなら、電源ボタンを 1 回押してください。

PC か Android の Chrome / Edge で着せ替えサイトを開き、「接続」から M5StopWatch を選びます。時刻は接続したときに自動で合います。

本体の操作: 時計画面で B = アプリ一覧、A と B を同時に長押し = いつでも時計に戻る。

元に戻すには

ダウンロードモードにして、手順 2 で取ったバックアップを書き戻します。

バックアップが無い場合は、M5Stack が公式に配布しているファームウェアを書き込んでください。
